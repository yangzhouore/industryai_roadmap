# Frontend visual specification

## Reference target
Review https://ai-digest.liziran.com/en/ when available. Mimic calm editorial hierarchy and reading experience; no pixel-exact proprietary imitation or copied visual assets.

## Visual
Restrained palette, strong typography, generous whitespace, compact header/footer, readable content width, consistent story numbering, image cards with meaningful alt text. Support mobile, tablet and desktop.

## Homepage
Brand/header, language switch, latest edition with date/title/3 teasers/source count, earlier edition cards, footer.

## Digest
Headline/date, table of contents, 1–3 feature stories with numbered sections, clear citation/source links, quick bites, next/prev issue navigation.

## Sources
Show counted source candidates, highlights/notable candidates, original URLs and scoring explanation. Do not imply third-party endorsement.

## Archive/search
Month grouping, query field, filters when backed by data; empty results state and pagination.

## Functional quality
WCAG-minded keyboard/focus/contrast, semantic headings, metadata, persistent locale across navigation, stable loading/skeleton and failure states. Browser visual comparisons if available.
